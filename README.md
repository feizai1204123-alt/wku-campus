# WKU campus (温州肯恩大学) – interactive 3D

Live: https://feizai1204123-alt.github.io/wku-campus/  (older versions: real-v1 … real-v8.html)

- Map data © OpenStreetMap contributors, ODbL.
- three.js r160 (MIT), meshoptimizer decoder (MIT).
- v9: 温肯楼 is modelled and lit in Blender (Cycles-baked lightmaps: GI, AO, soft sun shadows), loaded lazily from `baked/`.

## CC0 assets used in baked/
- HDRI: "Kloofendal 48d Partly Cloudy (Pure Sky)", Greg Zaal, Poly Haven (https://polyhaven.com), CC0.
- Textures: ambientCG (https://ambientcg.com), CC0 – Bricks066, Concrete034, RoofingTiles001, PavingStones128, Grass004, Asphalt026C, Tiles143, Plaster001.
